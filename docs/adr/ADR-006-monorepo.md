# ADR-006: モノレポ構成を採用

**ステータス**: 承認済み  
**日付**: 2026-07-05

## コンテキスト

Go・Python・Next.jsの3サービスを1人で開発・管理する。

## 決定

単一リポジトリ（モノレポ）で全サービスを管理する。

## 理由

- 全体設計を1つのリポジトリで俯瞰できるため、ポートフォリオとして価値が高い
- Railway・Vercelともにサブディレクトリ指定のデプロイに対応
- GitHub ActionsのCIワークフローを一元管理できる
- Claude CodeのPRレビューが全サービスにまたがる変更を一度に確認できる

## 不採用案

- **マルチレポ**: チーム開発では一般的だが、個人開発では管理コストが増加するだけで恩恵が薄い。
