# ADR-001: APIサーバーにGoを採用

**ステータス**: 承認済み  
**日付**: 2026-07-05

## コンテキスト

複数ユーザーの複数銘柄（最大ユーザー数 × 50銘柄）を毎分並行して監視する常時稼働サーバーが必要。

## 決定

Go 1.22 を APIサーバーに採用する。

## 理由

- goroutine による軽量な並行処理で、数千銘柄の同時監視が可能
- 常時稼働サーバーとして低メモリ・高スループットを実現
- 静的型付けによる安全性とコンパイル時エラー検出

## 不採用案

- **Node.js**: イベントループベースで並行処理の柔軟性がGoに劣る
- **Python**: GILにより真の並行処理が困難
- **Rust**: 学習コスト高・開発速度が低下する
