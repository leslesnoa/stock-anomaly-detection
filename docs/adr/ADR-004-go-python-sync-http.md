# ADR-004: Go-Python間通信に同期HTTPを採用

**ステータス**: 承認済み  
**日付**: 2026-07-05

## コンテキスト

GoのAPIサーバーが異常を検知した際、PythonのREST APIを呼び出してテクニカル分析・ニュース取得・Claude API連携・Slack通知を依頼する必要がある。

## 決定

Go から Python へ同期 HTTP リクエストを送信する。PythonはSlack通知まで完了した後、AIレポートテキストをレスポンスとして返す。GoはレスポンスをPostgreSQLへ保存する。タイムアウトは30秒。

## 理由

- 実装がシンプルで、デバッグ・監視が容易
- 異常検知の頻度は低く（2.5σ超え）、Pythonへのリクエスト数は限られるため同期でも十分
- 追加のキューインフラが不要

## 不採用案

- **Redis Queue（非同期）**: GoとPythonのデカップリングや独立スケールのメリットはあるが、本プロジェクトの規模では実装複雑度が過剰。
- **gRPC**: 型安全なインターフェース定義とストリーミングのメリットはあるが、protoファイル管理などのオーバーヘッドが現フェーズでは不要。
