# ADR-002: 分析エンジンにPythonを採用

**ステータス**: 承認済み  
**日付**: 2026-07-05

## コンテキスト

RSI・MACD・ボリンジャーバンドなどのテクニカル指標計算と、統計的異常検知（Z-score）を実装する分析エンジンが必要。

## 決定

Python 3.11 を分析エンジンに採用し、Goとは HTTP で通信する。

## 理由

- pandas / numpy による金融分析ライブラリが充実
- Goとの責務分離により、各言語の強みを活かした設計
- Finnhub News API・Claude API との連携もPythonエコシステムで完結

## 不採用案

- **Go**: 金融分析ライブラリが乏しく、pandas相当の実装を自前で行う必要がある
- **R**: Web API との組み込みが難しく、Railwayへのデプロイコストが高い
